# AirPlaneGame

欅祭で公開した、飛行機を操作する短編ゲームです。

**プレイはこちら：**  
https://unityroom.com/games/hikoukitimer

## 使用技術・開発環境

- C#
- Unity
- Visual Studio
- Git / GitHub
- CLIP STUDIO PAINT（イラスト・素材制作）

## 担当内容

- ゲーム内のプログラム実装
- 飛行機の操作・挙動の実装
- ゲーム内イラスト・素材の制作

※担当した内容に合わせて調整してください。

## 使用素材

- 効果音：効果音ラボ「雷魔法4」  
  https://soundeffect-lab.info/sound/search.php?s=%E9%9B%B7

上記以外のイラスト・素材は自作です。

## 動作環境

- 主な対象：スマートフォン（モバイルブラウザ）
- PCブラウザでもプレイ可能

## 開発目的

欅祭での展示・公開を目的として制作したゲームです。
